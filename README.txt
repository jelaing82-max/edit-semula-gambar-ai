EDIT SEMULA GAMBAR AI — V5 ONLINE READY

V5 direka untuk deployment awam:
- Premium mobile UI
- AI image editing backend
- API key server-side
- Local browser history
- No server-side image history/database required
- Node.js 24
- Express backend
- Health endpoint /api/health

DEPLOYMENT:
1. Upload/push folder ini ke GitHub.
2. Import repository ke Vercel.
3. Set Node.js 24.x if needed.
4. Add environment variable:
   OPENAI_API_KEY = API key anda
   OPENAI_IMAGE_MODEL = gpt-image-2
5. Deploy.
6. Buka URL Vercel pada telefon.

PENTING:
- Saya tidak boleh membuat URL awam tanpa akses ke akaun hosting anda.
- Jangan masukkan API key dalam index.html.
- Penggunaan API imej boleh dikenakan caj mengikut akaun/API semasa.
- Untuk aplikasi komersial, tambah login sebenar, database, rate limiting dan billing.
